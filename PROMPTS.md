# AI Usage Log - ABTalks Redesign

## Project Overview
Redesigned ABTalks' 60-day coding challenge platform with a mobile-first approach (390px viewport). Built three screens: Landing Page, Student Dashboard, and Challenge Day page.

## Thoughtful Idea: Focus Mode + Night Mode
- **Focus Mode**: Distraction-free builder view with just the task and submission form
- **Night Mode**: Toggle between light and dark themes, optimized for late-night coding

## Tech Stack
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Lucide React (icons)
- Mock data in JSON/TS files
